# Portfolio

A modern, responsive portfolio website built with React, TypeScript, and Supabase. Features an admin dashboard for managing content dynamically.

## 🚀 Features

- **Modern Tech Stack**: React, TypeScript, Vite
- **Admin Dashboard**: Full CRUD operations for portfolio content
- **Authentication**: Supabase authentication with email/password
- **Content Management**: Manage projects, skills, profile, hero section, and footer
- **File Uploads**: Resume/CV upload support
- **Responsive Design**: Mobile-first, fully responsive
- **Dark/Light Mode**: Theme toggle support
- **Real-time Data**: Powered by Supabase

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, shadcn/ui
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Hosting**: Vercel (recommended)
